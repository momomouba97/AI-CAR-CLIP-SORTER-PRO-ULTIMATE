# الاختبارات

قبل النشر، اختبر على جهاز macOS Intel فعلي:
- استيراد فيديو H.264/AAC.
- اكتشاف المشاهد بنوعي Content وAdaptive.
- التصدير والتحقق من الصوت والصورة.
- اختيار مجلد حفظ بمسار يحتوي مسافات وأحرف غير لاتينية.
- فرز مقطع ثم التراجع.
- تشغيل معاينة الفيديو والصوت.
- رفع فيديو تجريبي بحالة Private فقط بعد إعداد OAuth.

هذه الحزمة لا تدّعي أن الاختبارات على جهاز Big Sur قد نُفذت بالفعل.
