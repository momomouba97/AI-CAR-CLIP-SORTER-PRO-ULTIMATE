# AI CAR CLIP SORTER PRO ULTIMATE

تطبيق مكتبي لمعالجة مقاطع السيارات على macOS، يتضمن اكتشاف المشاهد، تصدير المقاطع، فرزها، وخيار رفعها إلى YouTube بعد إعداد OAuth.

## المتطلبات

- macOS Big Sur 11.7.11 أو أحدث.
- جهاز Intel Mac.
- لاستخدام البناء: GitHub Actions.
- التطبيق مبني بواجهة PySide6 ويستخدم PySceneDetect وFFmpeg.

## البناء عبر GitHub بمرحلة واحدة

1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. افتح تبويب Actions.
3. اختر `Build macOS Intel DMG`.
4. اضغط `Run workflow`.
5. بعد نجاح العملية، افتح صفحة التشغيل (workflow run).
6. حمّل Artifact باسم `AI-CAR-CLIP-SORTER-PRO-MAC-INTEL-DMG`.
7. فك ملف DMG وافتح التطبيق.

ملاحظة: يجب أن يكون Runner المسمى `macos-15-intel` متاحاً لحساب GitHub. إذا لم يكن متاحاً، عدّل `runs-on` إلى Intel runner مدعوم في حسابك. لا تستخدم Apple Silicon runner لإنتاج نسخة Intel إلا بعد ضبط البناء المتقاطع واختباره.

## المعالجة المتتابعة لمجلد فيديوهات (Batch Queue)

1. من تبويب «تقسيم الفيديو»، اضغط «اختيار مجلد فيديوهات».
2. يستورد التطبيق ملفات الفيديو المدعومة مباشرة من المجلد.
3. يرتب الملفات ترتيباً طبيعياً حسب الاسم والترقيم؛ مثلاً `video2.mp4` قبل `video10.mp4`.
4. اضغط «معالجة جميع الفيديوهات بالترتيب».
5. يحلل التطبيق الفيديو الأول، ويصدّر مشاهده تلقائياً، ثم ينتقل إلى الفيديو التالي حتى تنتهي القائمة.
6. عند تفعيل الرفع التلقائي من الإعدادات، ينتظر التطبيق انتهاء رفع مقاطع الفيديو الحالي قبل الانتقال إلى المصدر التالي.
7. زر «إيقاف بعد الفيديو الحالي» يمنع بدء فيديو جديد بعد اكتمال الفيديو الجاري.

الصيغ المدعومة: MP4 وMOV وMKV وAVI وM4V وWEBM. يتم تصدير المقاطع إلى مجلد `ClipsCars` داخل مجلد الإخراج المحدد.

## تقسيم الفيديو

- اختر فيديو المصدر.
- اضبط نوع الكاشف والحساسية والحد الأدنى لمدة المشهد.
- اضغط تحليل واكتشاف المشاهد.
- فعّل التصدير التلقائي إذا أردت بدء التصدير مباشرة بعد التحليل.
- اختر مجلد الحفظ.
- تُصدّر المقاطع بصيغة MP4 مع صوت AAC.

## فرز المقاطع

ضع المقاطع المراد فرزها داخل مجلد `ClipsCars` في مجلد الحفظ المختار. استخدم:
- 1: MovingCars
- 2: StoppingCars
- 3: ExcludedCars
- Space: تخطي
- Ctrl+Z: تراجع

## رفع YouTube الاختياري

ميزة الرفع تحتاج إعداداً خارجياً لمرة واحدة:
1. أنشئ مشروعاً في Google Cloud.
2. فعّل YouTube Data API v3.
3. أنشئ OAuth Client ID من نوع Desktop App.
4. نزّل ملف JSON الخاص ببيانات OAuth.
5. من إعدادات التطبيق اختر الملف وفعّل الرفع التلقائي.
6. عند أول رفع، يفتح المتصفح لتسجيل الدخول ومنح الصلاحية.

لا تضع ملف OAuth JSON في مستودع GitHub العام. احتفظ به محلياً.

## حدود الإصدار الحالي

- اكتشاف المشاهد يعتمد على تغير الصورة، وليس على فهم AI لمحتوى السيارات.
- التصنيف Moving/Stopping يدوي من المستخدم.
- رفع YouTube يخضع لحصص API وسياسات الحساب.
- التقدّم في تحليل المشاهد متحرك لأن PySceneDetect لا يوفر نسبة دقيقة في هذا التنفيذ.
- يلزم اختبار ملف DMG الناتج فعلياً على macOS Big Sur Intel قبل اعتباره إصداراً نهائياً.
- توقيع Apple Developer ID وNotarization غير مضمنين؛ لذلك قد يعرض macOS تحذيراً عند أول تشغيل.

## استكشاف الأخطاء

- إذا لم يعمل الفيديو في المشغل، جرّب ملف MP4 بترميز H.264/AAC.
- إذا فشل بناء DMG، افتح سجل GitHub Actions وانسخ الخطأ كاملاً.
- إذا فشل YouTube OAuth، تحقق من إعداد OAuth Client ID وتفعيل YouTube Data API v3.
